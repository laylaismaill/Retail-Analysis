# 🛍️ Retail Analysis Dashboard (Power BI)

## 📋 Overview
This is a Retail Analysis Dashboard created using Power BI.  
It analyzes sales and profit data across different products, categories, and regions to help retail managers understand performance and identify trends.

---

## 🎯 What This Dashboard Shows
- Total sales and profit  
- Sales by product category and region  
- Customer segmentation and purchasing trends  
- Year-over-year growth and KPIs  
- Top-performing and low-performing products  

---

## 🧠 What I Did
- Cleaned and transformed the data in Power Query  
- Built relationships between data tables  
- Created DAX measures (e.g., total sales, profit margin, YOY growth)  
- Designed clear visuals and slicers for easy interaction  

---

## 🛠 Tools Used
- Power BI Desktop  
- Power Query  
- DAX (Data Analysis Expressions)  
- Excel / CSV for data sources  

---

## 🚀 How to Open It
1. Download the file Retail_Analysis-S1.pbix  
2. Open it in Power BI Desktop  
3. Explore sales data using the visuals and filters
